# RentMate: Project Management Plan

Academic project (PJATK): full project plan for **RentMate**, a peer-to-peer item-rental application (listings, search, reservations, online payments with deposits, user support), with a planned budget of **500,000 PLN**. Planned timeline: **28 Oct 2026 – 7 Oct 2027**.

## What is inside
| File | Description |
|---|---|
| `Project_Charter.pdf` | Project charter: problem, goals, success criteria, risks |
| `WBS.pdf` | Work breakdown structure |
| `Gantt_Schedule.pdf` | Schedule with durations, dependencies and assigned resources (157 rows) |
| `RentMate.pod` | Original ProjectLibre file |

## Plan at a glance
- **Hierarchical WBS: 7 phases, 157 tasks and milestones**, numbered by level (e.g. 5.4.1).
- Phases: 1.0 Project management and documentation · 2.0 Application design (functional, UI/UX, technical architecture) · 3.0 User module · 4.0 Listings and search · 5.0 Reservations, payments and returns · 6.0 Security and user support · 7.0 Testing (functional, integration and security, UAT, acceptance).
- Each module is split into Frontend, Backend and Integration, with finish-to-start **task dependencies**.
- **7 milestones** mark the end of each phase, ending with application acceptance on 4 Oct 2027.
- **5 resource roles:** Project Manager, UI/UX Designer, Frontend Developer, Backend Developer, QA Engineer, with hourly rates and **resource leveling** (partial allocations such as 50% or 88%) to avoid overloading people.
